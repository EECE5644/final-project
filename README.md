# SIMPLE INTRODUCTION

- [main.py](./main.py) is the main script of this project. You can run it to reproduce the experiment.
- [classify.py](./classify.py) can be used to classify news articles via the best model.
- [runner.py](./runner.py) organize the experiment end-to-end.

- [config.py](./config.py) contains the configuration settings for the experiment, including hyperparameters and file paths.
- [preprocessor.py](./preprocessor.py) for preprocessing the data.
- [vectorizers.py](./vectorizers.py) contains the vectorizers used in this project.
- [dl.py](./dl.py) contains the deep learning model and training code.
- [models.py](./models.py) contains all the models used in this project.
- [evaluator.py](./evaluator.py) contains the evaluation functions.
